# CJK fonts

PokketSX downloads these on demand when the interface language is Japanese, Korean or Simplified Chinese, so the on-screen display and Big Picture mode can render those scripts (`src/duckstation-qt/qttranslations.cpp`). They are not shipped with builds.

They are the Regular weights of Noto Sans CJK, release Sans2.004, from https://github.com/notofonts/noto-cjk (`16_NotoSansJP.zip`, `17_NotoSansKR.zip`, `18_NotoSansSC.zip`), licensed under the SIL Open Font License 1.1 (see `LICENSE`).
